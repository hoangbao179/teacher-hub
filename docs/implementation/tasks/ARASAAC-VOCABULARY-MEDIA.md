# ARASAAC Vocabulary Media

## Mục tiêu

Dùng ARASAAC làm nguồn mặc định cho hình minh họa trong Kho từ vựng, giữ Pixabay
cho ảnh thật tùy cấu hình, đồng thời làm chắc luồng search → import → lưu bộ từ →
assignment/game.

## Phạm vi

- Contract, cấu hình, provider registry và ARASAAC integration.
- Cache/resolver, download/WebP, deduplicate và cleanup file lỗi.
- Validation/promote stored media trong transaction lưu bộ từ.
- Picker/bulk suggestion responsive và thông điệp theo provider thực tế.
- Unit, integration, targeted E2E và đánh giá live chín truy vấn mẫu.

## Không thuộc phạm vi

- Không xóa Pixabay/upload.
- Không đổi route API hoặc business rule assignment/game.
- Không thêm migration, object storage hoặc tải kho ARASAAC về máy chủ.
