# Admin UI refresh wireframes

Bộ ảnh này là design handoff cho việc refresh giao diện quản lý giáo viên.

## Ảnh được duyệt làm visual target

1. `01-dashboard-desktop-approved.png`
2. `02-dashboard-mobile-390-approved.png`
3. `03-dashboard-mobile-360-approved.png`

Ba ảnh trên được render từ prototype HTML bằng Playwright và là target chính cho
Dashboard. `dashboard-concept.html` được giữ lại để kiểm tra bố cục và spacing.

## Ảnh giải thích hệ thống thiết kế

- `00-design-system-board.png`: palette, component, spacing và illustration direction.
- `04-dashboard-desktop-handoff.png`: chú thích desktop.
- `05-dashboard-mobile-handoff.png`: chú thích mobile.

Các board có thể chứa text/số liệu minh họa. Không dùng chúng để thêm feature, dữ
liệu hoặc menu. Business rule và source hiện tại luôn có ưu tiên cao hơn.
